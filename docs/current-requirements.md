# ItemLife 当前需求基线

> 更新日期：2026-10-10。本文描述当前产品行为，是开发与验收的优先依据；`design-report.html` 保留架构论证与历史规划，若两者有冲突，以本文和可执行测试为准。

## 1. 产品模型

ItemLife 同时管理资金流和物品成本。`transactions` 是金额的唯一权威来源；账户余额、物品成本和综合看板均由流水派生。

- “记账”和“记物”共用“记一笔”入口。
- 支出中的物品清单为空，就是普通记账。
- 添加新建物品、关联物品、附加物品或附加费用后，该支出同时形成可追溯的物品归属树。
- 物品页是管理和分析页，不提供脱离流水的新增配件批次入口。
- 金额一律保存为整数分；时间以 UTC 入库，界面按本地时间展示。

## 2. 当前功能范围

### M1 认证与安全

- 邮箱、强密码注册，Argon2id 哈希保存。
- 站点首个注册账号自动成为超级管理员；后续账号默认为普通用户。
- 超级管理员可开启或关闭公开注册，并授予或移除站点管理员权限。
- 关闭公开注册时，注册页显示“私有站点，禁止注册”，仅接受管理员生成的 8 位、单次使用、7 天有效邀请码。
- 超级管理员和站点管理员可查看用户、生成/撤销邀请码，以及停用/恢复普通用户；停用保留账本数据并立即撤销全部登录状态。
- 超级管理员可重置其他用户密码并立即撤销其全部会话。用户必须先停用才能由超级管理员永久删除；永久删除清理其个人数据和其创建的家庭数据，其在其他家庭创建的共享记录保留，但创建者改为已删除用户。
- 站点管理员不能修改注册开关、管理其他管理员或超级管理员；任何人都不能停用自己。
- 登录、TOTP 两步验证、一次性恢复码。
- Access Token 仅存内存；Refresh Token 使用 HttpOnly Cookie 并执行旋转和盗用检测；合法并发刷新提供 30 秒宽限，避免多标签页和 Safari 页面恢复被误判为令牌重放。
- MFA 设置、关闭、全部设备登出和结构化安全审计。
- 用户可在“我的”修改昵称；昵称同步显示在侧栏、家庭成员和操作记录中，邮箱保持账号唯一标识。
- 后续邮箱验证和忘记密码按 `docs/email-verification-feasibility.md` 实施；本期只完成方案，不启用邮件发送。

### M2/M3 记账与物品

- 收入、支出、转账；账户、分类、时间、备注和幂等提交。
- 支出可选物品清单，支持多个一级物品和任意层级子项。
- 一级项支持“新建物品”和“关联物品”；子项支持“附加物品”和“附加费用”。
- 配件必须填写数量；批次总额不能整除数量时，余数计入第一件，确保金额守恒。
- 流水编辑展示并修改物品树、名称、金额和配件数量。
- 删除流水会联动删除由其创建的物品或配件；删除物品或配件会扣减来源流水金额，并处理跨流水子项。
- 物品页保留状态管理、配件使用/撤销/删除、成本指标、成本演进和关联流水。
- 物品详情提供返回物品页的明确入口；页面内返回和浏览器返回都会恢复刚才访问的物品位置，并短暂强调对应卡片。
- 物品成本指标：总支付、当前持有成本、日均持有成本、配件库存价值、预计日均成本和未分摊提示。

### M4 家庭协作

- 用户可创建多个家庭；创建者是 owner，创建家庭时生成家庭预置分类。
- owner 可生成 8 位邀请码；默认 72 小时有效、最多使用 5 次，可主动使其失效。
- 邀请码排除 `0/O/1/I`，仅在创建响应显示明文，数据库只保存 SHA-256。
- 用户可凭有效邀请码加入家庭；重复加入、过期、用尽或失效邀请码必须被拒绝。
- 家庭角色分为创建者、管理员和普通成员。创建者可修改/删除家庭并授予或移除管理员权限；管理员可管理邀请并移除普通成员。
- 普通成员和管理员可主动退出；创建者不能退出或移除自己。管理员不能管理其他管理员或创建者。
- 创建者删除家庭前必须输入完整家庭名称二次确认；删除在同一事务内永久清理该家庭的账户、分类、流水、物品、配件、库存记录、邀请和成员关系。
- 创建者、管理员和普通成员都能查看和维护家庭账户、分类、流水和物品；`created_by` 保留操作人追溯。
- 全局数据域选择器提供个人账本和用户加入的各个家庭。切换后，所有列表、表单和看板统一读写该数据域。
- 个人数据不会出现在家庭域；退出或被移除后立即失去家庭域访问权。

### M5 综合看板

- 总览卡：区间消费、储蓄、收益和当前总资产。
- 消费与储蓄显示与上一等长周期的变化百分比。
- 收益包括投资收益分类与自动结息流水。
- “收支与总资产趋势”支持日、周、月粒度，同时绘制全部收入、全部支出和期末总资产，三条曲线使用统一纵坐标。
- 分类占比按区间支出聚合；账户分布使用实时派生余额。
- 物品投入展示累计支付、当前持有、配件库存、在役和在册数量。
- 看板沿用全局个人/家庭数据域，并提供近期流水。
- 图表按需加载 ECharts，响应手机、平板和桌面；同时提供表格形式的数据替代视图。

### 运维日志

- 容器日志由 `log-collector` 汇总到持久化日志卷，每 12 小时批量落盘；累计达到 20 MB 时提前落盘并分片。
- `docker stop`、Compose 重建等正常停止会在退出前强制落盘。主机断电、进程崩溃或 `SIGKILL` 仍可能丢失本批次尚未落盘的日志。

## 3. 数据域约定

- 查询：省略 `domain` 或使用 `domain=user` 表示个人；家庭使用 `domain=household:<uuid>`。
- 新建：请求体使用 `owner:{type:'user'}` 或 `owner:{type:'household',id}`。
- 按 ID 更新、删除时，后端从记录反查归属并校验成员关系。
- 无权访问和资源不存在统一返回 404，避免探测他人家庭或记录。
- 账户和分类缓存始终只保存当前数据域；主页面缓存按数据域键隔离，切换后不得展示前一数据域内容，迟到的旧请求不得覆盖新域数据。

## 4. UI 与交互约定

- 全站下拉与日期时间选择使用 `AppSelect`、`AppDateTimePicker` 等自实现控件，不调用浏览器原生 `<select>`、`date`、`time` 或 `datetime-local`；日期时间面板锚定输入框以下拉形式展开，不使用遮罩弹窗。
- 移动端普通表单优先两列；短操作按钮按内容宽度，不强制占满半行。
- 桌面端同一业务行尽量容纳完整字段；移动端复杂物品行最多两行，控件高度一致。
- 物品页移动端的状态与物品名称筛选保持同一行；“当前数据域”标签与选择器分别贴近容器两侧。
- 支出/收入/转账、路由切换和弹窗使用短时淡入淡出与轻位移动画；遵守系统“减少动态效果”设置。
- 首页、流水、物品、家庭和“我的”保留各数据域内的筛选、列表与滚动位置；返回时先显示缓存内容并后台刷新。新建、详情、编辑和认证页面不缓存，页面内未提交弹窗离开时关闭。
- 登录并完成首屏后，浏览器空闲时分批预取登录区一级、二级页面代码并预热当前数据域的账户与分类；开启节省流量时停止主动预取，具体物品详情数据仍按需加载。
- 弹窗背景渐进模糊；只有按下和抬起都发生在背景时才关闭。
- 桌面侧栏保留“家庭”主入口，并将账户、分类、安全和站点管理统一归入“我的”；移动端保留“首页 / 流水 / 记一笔 / 物品 / 我的”五个入口及凸起的“记一笔”图标。
- “我的”按账户身份、账本设置、协作与安全、站点管理和当前会话分层；管理子页通过“我的 / 当前页”面包屑返回，账号安全改用 `/me/security`，旧 `/settings` 页面和路由不再保留。
- 所有可操作区域至少 44×44px；危险删除必须确认并明确联动影响。
- 360–2560px 不得产生页面级横向滚动；图表和长表格允许在自身容器内适配或滚动。

## 5. 验收

1. 两个账号通过邀请码组成家庭，在同一家庭域看到相同账户、流水、物品和看板。
2. 个人域数据在家庭域不可见；非成员访问家庭域返回 404。
3. 邀请码过期、用尽或主动失效后无法加入；普通成员不能生成邀请或移除成员，管理员不能任免或移除其他管理员。
4. 指定区间的支出、收入、储蓄、收益、分类占比与流水手工核算一致。
5. 趋势图各期总资产与账户余额沿流水回溯的结果一致；当前总资产与账户页余额合计一致，物品投入与物品页总览一致。
6. 个人/家庭切换后，账户、分类、流水、记一笔、物品和看板同时切换，不出现前一数据域残留。
7. 前后端类型检查、生产构建、既有 M1–M3 冒烟和 `smoke:m4m5` 全部通过。
8. 首位用户成为超级管理员；关闭注册后无邀请码不能注册，有效邀请码只能使用一次且过期/撤销后失效。
9. 超级管理员与管理员的权限边界符合约定；停用普通用户后，其现有 Access Token、Refresh Token 和新登录立即失效，恢复后可重新登录。
10. 超级管理员重置密码后旧密码与现有会话失效；未停用用户无法永久删除，停用后永久删除会清除该用户及其个人/自有家庭数据，同时保留其他家庭的共享流水。

## 6. 暂不包含

- 家庭预算、审批流、创建者转让和自定义权限角色。
- 数据在个人与家庭之间直接迁移。
- 多币种换算、原生 App、OCR 和提醒推送。
- M6 的完整 Playwright 多视口回归、安全专项和正式发布流水线。
